# trendtaker

Work in progress. Not ready for use yet.

Tracks GitHub repository metrics day by day to find what is trending.

Instead of scraping the trending page, it collects stars, forks and
open issues through the GitHub REST API and compares daily snapshots.



-GitHub 리포 지표 기반 일간 트렌드 추적기  
-매일 stars 증가량으로 뽑은 GitHub 트렌딩을 알려드립니다.



## Stack

Kotlin, Spring Boot, MySQL, Flyway
